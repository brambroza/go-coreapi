# GoAlong Core API Skills

ชุด skill นี้ทำไว้สำหรับช่วย AI/agent ทำงานในโปรเจค `coreapi-new` โดยอิงจากโครงสร้างจริงของ repo:

- ASP.NET Core API บน `.NET 9`
- SQL Server ผ่าน EF Core และ helper `DB.DBConn`
- Autofac auto-register service classes ที่ชื่อจบด้วย `Service`
- JWT authentication, Swagger, CORS, static files
- SignalR hubs และ RabbitMQ background log processing

## Skills

- `goalong-project-orientation` - อ่านภาพรวมโปรเจคก่อนเริ่มงาน
- `goalong-api-controller` - เพิ่มหรือแก้ controller/API endpoint
- `goalong-database-sql` - ทำงานกับ EF Core, stored procedure, raw SQL, DataTable
- `goalong-auth-session` - แก้ auth, JWT, login, account/session
- `goalong-realtime-background` - แก้ SignalR, RabbitMQ, hosted service
- `goalong-verification` - build/test/checklist ก่อนส่งงาน

## Usage

เมื่อเริ่มงานใน repo นี้ ให้เปิด skill ที่ตรงกับงานก่อนเสมอ และใช้ `goalong-project-orientation` เป็นตัวตั้งต้นถ้ายังไม่รู้ขอบเขตงาน.
